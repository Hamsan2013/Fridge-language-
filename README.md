# FRIDGE Programming Language

**Created by: Hamsan A**

FRIDGE is an independent, general-purpose programming language designed to read like clear English. There are no cryptic symbols, no complicated scoping rules, and no unnecessary punctuation.

## Core Philosophy
* **English-like Syntax:** Write real programs using natural, readable instructions.
* **Works Wherever:** Native C++17 architecture ensures `.frg` programs and `.uzip` packages run on Windows, Linux, macOS, and Raspberry Pi.
* **2D, 3D, and Desktop Ready:** Built-in support for `ask`, `listen`, `add OBJ` 3D hierarchies, and declarative desktop UIs.

## CLI Usage
* Check version: `fridge version`
* Validate syntax: `fridge check main.frg`
* Run program: `fridge run main.frg`
* Run package: `fridge run MyGame.uzip`
